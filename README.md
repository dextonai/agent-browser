A browser automation agent powered by AI.

## Features

- 🤖 AI-powered browser automation
- 🌐 Web interaction and scraping
- 📊 Data extraction and analysis
- 🔒 Secure and sandboxed

## Quick Start

```bash
# Clone the repo
git clone https://github.com/dextonai/agent-browser.git
cd agent-browser

# Install dependencies
npm install

# Run the agent
npm start
```
